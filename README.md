# Projeto 2WW

<img src="logo.png" width="200" height="200" />

>Inserir uma logo para o projeto

>O 2WW é uma plataforma web que tem como objetivo ser a principal fonte de informações e o guia digital do evento WTADS, centralizando todo o conteúdo importante para os participantes. Esta solução foi desenvolvida para resolver o problema da falta de um lugar central para os participantes encontrarem informações, cuja divulgação em redes sociais e sites deixa o conteúdo disperso, difícil de acompanhar e prejudicando a experiência geral. A plataforma visa reunir todas as informações, oferecendo um cronograma dinâmico que exibe horários e localização dos eventos, uma área dedicada a apresentar os palestrantes com seus perfis e temas, e uma seção com informações sobre os minicursos. O foco é criar um sistema simples e acessível que melhore a experiência dos participantes, garantindo que ninguém perca nada importante.
